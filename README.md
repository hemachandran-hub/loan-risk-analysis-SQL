# Loan Risk Prediction 

An end-to-end SQL data analysis project evaluating loan portfolio risk, borrower default patterns, demographic credit metrics, and financial risk segmentation using MySQL.

---

## 📋 Project Structure

* **`Loan_.sql`**: Complete database creation script, dataset import inserts, exploratory data queries, and advanced credit risk analytical scripts categorized by topic.

---

## 🔍 Key Analytical Topics Covered

1. **Portfolio Overview & Demographics**: Analyzing total loan volumes, aggregate loan amounts, education levels, and borrower employment distributions.
2. **Data Integrity & Validation**: Checking for duplicate records and validating numerical ranges for key features (`age`, `credit_score`, `dti_ratio`, `interest_rate`).
3. **Credit Risk & Default Analysis**: Calculating baseline default rates and evaluating risk exposure across different loan purposes and employment types.
4. **Cohort & Segment Risk Modeling**: Evaluating default behavior across age brackets, credit score bands (`Poor`, `Fair`, `Good`, `Excellent`), and the presence of co-signers.

---

## 🛠️ Technologies Used
* **Database**: MySQL / MySQL Workbench
* **Language**: SQL (DDL, DML, CTEs, Window Functions, Case Statements, Aggregate Functions)
